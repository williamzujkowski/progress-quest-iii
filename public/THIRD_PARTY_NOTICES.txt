PROGRESS QUEST III — THIRD-PARTY NOTICES

This file ships with the PWA. It records direct production inputs; it does not
change their licenses or resolve the legacy-web-source ambiguity documented at
https://github.com/williamzujkowski/progress-quest-iii/blob/main/docs/content-provenance.md.

It is written to stay true without being re-dated. Names, authors and license
terms are recorded here because those are the durable facts. Which exact
revision shipped is not a durable fact, so it is not copied here: a hand-kept
"last updated" line reports when somebody last remembered to touch this file
rather than when it was last correct, and a hand-copied version number goes
quietly wrong on the next install — this file named a Lucide release that the
bundle had already moved past. Both have one answer that cannot drift:

  package-lock.json, which records exact versions, tarball URLs and integrity
  https://github.com/williamzujkowski/progress-quest-iii/blob/main/package-lock.json

and every edit to this file, with its date and its reason, is in the history:
  https://github.com/williamzujkowski/progress-quest-iii/commits/main/public/THIRD_PARTY_NOTICES.txt

PROGRESS QUEST

Progress Quest was created by Eric Fredricksen, principal author of the
separately retained web reference implementation.

Thank you. Progress Quest is the joke that turned into a genre: a role-playing
game that plays itself, honestly and without you, and is funnier for keeping an
entirely straight face about it. Every idle game since owes it something, and
this one owes it more than most: the tasks, the loot, the unearned promotions,
the whole shape of the thing. Fredricksen also released it under terms generous
enough that a project like this one is permitted to exist, which is its own
kindness and is reproduced in full below.

The original is at https://progressquest.com/ and remains the definitive
article. Play that one first.

APPLICATION ICONS

The favicon and both PWA icons are original artwork belonging to this project.
public/favicon.svg is the source; public/icon-192.png and public/icon-512.png
are rasterised from it at their stated sizes and are regenerated from that one
file rather than drawn separately.

No Vite starter asset remains in the tree. The favicon that shipped previously
was a byte-identical copy of the Vite mark, and the PWA icons were rasterisations
of it; the unused starter hero image and social-service sprite were removed
earlier. None of those marks are present any longer, so no trademark permission
is relied upon for the application's own identity.
